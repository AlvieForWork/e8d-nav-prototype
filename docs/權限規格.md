# EVERY8D 權限規格文件（實作唯一依據）

> 本文件分兩張表，對應兩種不同的檢查：
> - 表一「功能權限」：某角色能不能進入／使用某功能（可用 / 唯讀 / 不可用）。
> - 表二「資料存取範圍」：能進入的功能中，某角色看得到多大範圍的資料（全公司 / 僅自己部門 / 僅自己）。
> 同一功能可能兩張表都出現：先看表一能不能進，再看表二進來看多大。
> 標【待確認】者為產品決策，需 PM 拍板，實作前先確認或先照現值做並標 TODO。

## 身份
- 企業管理員（母帳號）
- 部門管理員（子帳號，管自己所屬部門）
- 一般使用者（子帳號，無管理權限）

---

## 表一、功能權限（能不能進／用）
值：可用 / 唯讀 / 不可用（看不到）

| 功能 | 企業管理員 | 部門管理員 | 一般使用者 |
|---|---|---|---|
| 總覽 | 可用 | 可用 | 可用 |
| 總覽 — 合約摘要 | 可用 | 【待確認】 | 【待確認】 |
| 訊息發送（簡訊/參數/預約） | 可用 | 可用 | 可用 |
| 訊息紀錄報表 — 發送查詢 | 可用 | 可用 | 可用 |
| 訊息紀錄報表 — 管理報表 | 可用 | 可用 | 不可用 |
| 帳務與點數 — 儲值 | 可用 | 可用 | 可用 |
| 帳務與點數 — 子帳號點數管理（撥點） | 可用 | 可用 | 不可用 |
| 帳務與點數 — 撥點查詢 | 可用 | 可用 | 不可用 |
| 組織與子帳號 — 子帳號管理 | 可用 | 可用 | 不可用 |
| 組織與子帳號 — 部門 | 可用（可編輯） | 唯讀 | 不可用 |
| 設定 — 帳戶設定（個人資料/密碼） | 可用 | 可用 | 可用 |
| 設定 — 帳戶設定（公司資訊/預約發送代表號） | 可用 | 【待確認】唯讀或不可用 | 不可用 |
| 設定 — 進階設定（點數預警/回覆轉寄/國際簡訊/發送回報/發票資訊） | 可用 | 可用 | 可用 |

備註：進階設定為帳戶／公司層級設定，三身份皆可進入。「能否編輯（而非只是看到）」若需再分級，另行定義；目前先記三身份皆可用。

## 表二、資料存取範圍（進來後看得到多大）
僅列「資料會依身份縮放範圍」的功能。範圍：全公司 / 僅自己部門 / 僅自己。
（訊息發送、個人資料/密碼等「資料本就屬於個人、範圍恆為自己」的功能不列入此表，因無縮放問題。）

| 功能 | 企業管理員 | 部門管理員 | 一般使用者 |
|---|---|---|---|
| 總覽（數據範圍） | 全公司 | 【待確認】自己部門 / 全公司 | 【待確認】自己 / 部門 |
| 訊息紀錄報表 — 發送查詢 | 全公司 | 僅自己部門 | 僅自己 |
| 訊息紀錄報表 — 管理報表 | 公司/部門/成員 | 僅自己部門 | （不可用，不適用） |
| 帳務與點數 — 子帳號點數管理（撥點） | 全公司 | 僅自己部門 | （不可用，不適用） |
| 帳務與點數 — 撥點查詢 | 全公司 | 僅自己部門 | （不可用，不適用） |
| 組織與子帳號 — 子帳號管理 | 全公司所有帳號 | 僅自己部門帳號 | （不可用，不適用） |
| 組織與子帳號 — 部門 | 全公司所有部門 | 僅自己部門 | （不可用，不適用） |

## Phase2（暫不納入）
帳單與帳務、訂閱方案、發票管理

## 待 PM 確認清單
1. 總覽數據範圍：部門管理員看自己部門還是全公司？一般使用者看自己還是部門？
2. 總覽—合約摘要：部門管理員、一般使用者看不看得到？（合約為公司敏感商業資料，如單價、合約期間；未來詳細合約另有專頁。建議僅企業管理員可見。）
3. 設定—帳戶設定公司層級（公司資訊、預約發送代表號）：部門管理員唯讀還是不可用？
4. 進階設定：三身份皆可「進入」已定；是否需再區分「可看 vs 可改」？

## 通用備註
- 前端依權限與範圍過濾只是體驗，正式版後端須再次校驗，不可僅依賴前端。
